## V14 (saved) — current live design
- **Artifact link:** unchanged - V14 touches only the homepage's static `index.html`, the first round of the mobile optimization pass (see `claude/isl-mobile-optimization-handoff.md`). `Main.dc.html`/`Dpdp.dc.html`/the published design-canvas artifact were not touched - matches how the V13 homepage changes were also made static-only, so a future re-publish of the design-canvas artifact would not carry these forward.
- **Changes - five mobile bugs fixed, all reported directly by the user from real iPhone screenshots at 390px width:**
  1. **A working mobile nav, finally.** Below 900px, `nav .nav-links{display:none !important}` hid every nav link with no replacement - visitors on a phone had no way to reach Practice Areas/DPDP Compliance/The Docket/Our Team/About except by scrolling all the way to the footer (this was flagged in the mobile-optimization handoff doc as "very likely the single biggest thing to fix"). Fixed by adding a hamburger icon button and a slide-down mobile menu panel (all five links plus "Get in Touch"), toggled via a small new JS block; the logo is now centered on mobile (`position:absolute; left:50%`) with the hamburger sitting to its left, since the user specifically flagged the off-center logo. This addressed both of the user's first two reported issues (no menu, and the only working nav being the footer at the bottom of the page).
  2. **The "How We Work" orbit graphic (the small circular "every matter orbits one point of contact" diagram in the approach section) no longer crops off the right edge on mobile.** It was a fixed 360x360px SVG with no responsive sizing, so on a 390px viewport (minus the section's 64px side padding) it overflowed and got cut off. Fixed with `max-width:100%; height:auto` on the SVG plus a tighter max-width (260px) and reduced section padding at the 640px breakpoint, so it now scales down and stays centered.
  3. **The homepage's "From our knowledge bank" Docket teaser section (added in V13) no longer squeezes three post cards into unreadably narrow, clipped columns on mobile.** This was exactly the gap flagged (but not yet fixed) in the mobile-optimization handoff doc - the grid had no mobile override and inherited generic `repeat(3, minmax(0,1fr))` behavior. Fixed by converting it to a single horizontally-scrollable row below 640px (`display:flex; overflow-x:auto; scroll-snap-type:x mandatory`), each card taking ~78% of the viewport width so the next one visibly peeks in from the edge - matching the user's own suggestion of "a single post horizontally scrollable thing."
  4. **The "Explore DPDP Compliance" button on the DPDP banner no longer bleeds off the right edge of the screen on mobile.** The banner was a single-row flex layout (text block + button) that didn't drop the button to its own line cleanly on narrow screens. Fixed by stacking the banner vertically below 640px (`flex-direction:column`) with the button spanning the full width beneath the text.
  5. **Versioning note:** the hamburger/mobile-menu is a genuinely new component (not a fix within an existing pattern), so per the project's standing versioning convention this moved to a new whole number (V13 → V14) even though items 2-4 are ordinary polish within the existing breakpoints.
- **Scope note for next round:** this pass only touched the homepage, since that's what the user's screenshots covered. The DPDP page, Docket (index + 3 posts), and Team page all share the exact same nav markup and almost certainly have the identical "no mobile menu, links only in the footer" gap - worth confirming with the user and applying the same hamburger-menu fix sitewide in a follow-up round rather than leaving it homepage-only.
- **Working source files:** none - `Main.dc.html`/`Dpdp.dc.html`/`canvas.json` unchanged, same reasoning as V13's homepage changes (static-only edit).
- **Static deployable site:** ivory-slate-legal-website-v14.zip. `index.html` only: nav markup restructured (added `.nav-toggle` hamburger button + `#mobile-menu` panel, `.nav-logo`/`.site-nav` classes added for mobile centering), new CSS for `.nav-toggle`/`.mobile-menu` plus mobile-only overrides for `#approach` SVG sizing, `.dpdp-banner` stacking, and `.docket-grid` horizontal scroll, and a new JS block wiring the hamburger toggle (open/close, closes on link click, closes automatically if resized back past 900px). Verified via Playwright at 390px (phone), 768px (tablet), and 1440px (desktop): zero broken images; hamburger menu opens/closes correctly and contains all five links plus Get in Touch; the orbit SVG stays within the viewport and centered; the Docket section renders as a scrollable single-card row; the DPDP banner stacks with the button at full width, no longer clipped; desktop screenshot confirms the nav, orbit graphic, and DPDP banner all render exactly as before (full horizontal nav visible, hamburger hidden via `display:none` above 900px) - the mobile fixes live entirely inside `@media (max-width:...)` blocks and don't touch desktop rendering.
